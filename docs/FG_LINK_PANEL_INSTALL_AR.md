# لوحة FG Link المستقلة

الحزمة تستخدم التصميم الحالي الأسود والأخضر النيون والإطارات الفضية، وأقسام المشتركات والتحكم، المستخدمين والصلاحيات، Android / LAN، وسجل النشاط، بالعربية والإنجليزية. تشمل خادم الحسابات وخدمة Direct VPS، وتدعم التطبيق الحالي 2.1.2. لا تحتوي حسابات أو أجهزة أو كلمات مرور أو مفتاح توقيع APK من أي تثبيت سابق.

## تثبيت جديد

المتطلبات: Ubuntu 24.04، صلاحية sudo، دومين أو دومين فرعي يشير إلى IP الخادم، والمنافذ 80 و443 و10086 غير مستخدمة ومتاحة. إذا كان هناك موقع/Caddy قائم، يتوقف المثبت قبل استبداله؛ يلزم تكييف إعداد البروكسي لذلك الخادم.

فك ضغط الحزمة وادخل مجلدها، ثم:

```bash
sudo bash install.sh
```

أدخل دومين هذا الخادم وبريد مسؤول الإدارة وعنوان IPv4 العام الخاص به. يولد المثبت كلمة مرور مستقلة، ويثبت PostgreSQL وAPI وCaddy وخدمة اتصال الأجهزة. افتح `https://YOUR_DOMAIN/panel`.

اقرأ كلمة المرور على الخادم:

```bash
sudo cat /opt/fg-link-panel/administrator-password.txt
```

التسجيل العام مغلق. حساب الإدارة الذي تحدده وحده يدير اللوحة. أنشئ حسابات العملاء من قسم المستخدمين، وسجل MAC واربطه بالحساب وحدد مخارج المشاهدة والتحكم. تُرفض الأجهزة غير المعتمدة حتى لو عرفت عنوان الخادم. لا يوجد سقف إجمالي لعدد الأجهزة المسجلة؛ القدرة التشغيلية تعتمد على الموارد.

ضبط جهاز على خادم ثانٍ يحتاج اختيار عنوان ذلك الخادم في Controller؛ لن ينتقل الجهاز من خادمك الحالي تلقائيًا. في التطبيق، اكتب عنوان HTTPS للخادم المستقل عند تسجيل دخول Direct VPS، ثم استخدم حساب المستخدم الذي أنشأته هناك.

## تحديث تثبيت قائم

```bash
sudo bash update-existing.sh
```

للتثبيت المستقل الجديد: يأخذ نسخة احتياطية للكود وقاعدة البيانات، ويحافظ على `.env` وحساب الإدارة والمستخدمين والأجهزة، ويعيد الكود السابق إذا فشل التحديث. لا ينشئ كلمات مرور جديدة. النسخ الاحتياطية داخل `/opt/fg-link-panel/backup-*`.

لخادم FG Link القديم ذي إضافة Direct الحالية: يستخدم المحدث المثبت بإصدار الحزمة في `/opt/fg-link-server`، ويحافظ على قاعدة البيانات وإعدادات النشر. لا يستبدل الخادم القديم بالتثبيت المستقل أو يرحّل حساباته إلى مخطط مختلف. يتوقف عند إعداد غير معروف. إذا كان المسار مختلفًا، مرّره عبر `FGRCK_INSTALL_DIR`.

## البريد والنسخ الاحتياطية

SMTP اختياري ويُضبط لكل خادم مستقل في `/opt/fg-link-panel/server/.env`، ثم `sudo docker compose up -d --no-deps api` من ذلك المجلد. لا ترسل بيانات البريد الخاصة بك لصديقك؛ يستخدم حسابه هو. استخدم اختبار البريد داخل التطبيق للتحقق من الإرسال الفعلي.

احتفظ بنسخة خاصة من `.env` وكلمة مرور الإدارة وقاعدة البيانات وقائمة الأجهزة `/var/lib/nexvary-direct-mttl/allowed-macs.json`. لا تنشر هذه الملفات. المثبت لا يعطّل جدار الحماية ولا يفتح قاعدة البيانات أو واجهة صيانة الأجهزة للإنترنت.
